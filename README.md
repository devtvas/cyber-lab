# 🛡️ Cyber Lab

Hands-on cybersecurity laboratory focused on **Blue Team, SOC, Cloud Security, DevSecOps, security automation and defensive security**.

> **Purpose:** document practical learning, experiments, investigations and security engineering exercises while transitioning from software engineering to cybersecurity.

## 🎯 Objectives

- Build practical cybersecurity skills through controlled laboratory exercises.
- Develop Blue Team and SOC fundamentals.
- Practice log analysis, incident investigation and detection engineering.
- Explore vulnerability management and remediation.
- Apply security practices to Cloud, containers and CI/CD pipelines.
- Automate repetitive security tasks with Python.
- Document findings clearly as they would be in a professional environment.

## 🔬 Methodology

Each lab should document:

1. **Objective** — what is being investigated or practiced.
2. **Environment** — operating system, tools and versions.
3. **Procedure** — reproducible steps.
4. **Evidence** — commands, logs, screenshots or relevant outputs.
5. **Analysis** — what the evidence means.
6. **Risk / Impact** — why the finding matters.
7. **Remediation** — how the issue can be mitigated.
8. **Lessons learned** — what was learned and what should be tested next.

## ⚠️ Ethics & Scope

All activities in this repository are intended for **authorized laboratory environments, local machines, intentionally vulnerable systems, CTFs and defensive/security-learning scenarios**.

No unauthorized access, credential theft, destructive activity or testing against third-party systems is performed.

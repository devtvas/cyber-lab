# Cybersecurity Learning Roadmap

## Phase 1 — Foundations

- TCP/IP
- DNS
- HTTP/HTTPS
- Linux
- Windows
- Authentication and authorization
- Basic cryptography
- Security principles

## Phase 2 — Blue Team

- Security logs
- Authentication events
- SIEM concepts
- Detection rules
- Alert triage
- IOC analysis
- Incident response
- MITRE ATT&CK

## Phase 3 — Vulnerability Management

- Vulnerability scanning
- CVE and CVSS
- Risk prioritization
- Remediation
- Verification

## Phase 4 — DevSecOps

- SAST
- SCA / dependency scanning
- Secret scanning
- Container security
- CI/CD security gates
- Secure software development

## Phase 5 — Cloud Security

- IAM
- Least privilege
- Secrets management
- Network security
- Logging and monitoring
- Secure workloads

## Phase 6 — Security Automation

- Python
- REST APIs
- IOC processing
- Log parsing
- Security reporting

The roadmap will evolve as practical labs are completed.
